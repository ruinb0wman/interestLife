# 躺平财务模拟器 · 不交社保版

通用收支模型：从「开始年龄」递推到「结束年龄」，收入与支出都是可自由增删的项，帮助找出「躺平不破产」的条件。

## 功能

- 按年递推现金流：投资收益 + 各项收入 − 各项支出；收入/支出都是通用项，引擎不感知「工资 / 生活费」这类分类。
- 每个收支项可设：名称、单次金额（元/次）、周期（仅一次 / 每 N 个月 / 每 N 年）、单次金额年涨幅、开始与结束年龄、启用开关。
- 基础信息只保留开始年龄、结束年龄、初始本金；「+ 添加」提供工资 / 零工 / 生活费 / 换车 / 老年医疗 / 大病等预设模板，老配置可一键复现。
- 投资收益率三档：普通 / 乐观 / 悲观；资不抵债即截断，不再推演负债雪球。
- 蒙特卡洛压力测试：随机收益率与各支出项涨幅逐年游走，输出存活成功率、最终资产分位与破产中位年龄。
- ECharts 双轴折线图（本金三情景 + 耗尽点 + 收入合计 / 支出合计两条线）、关键数据卡片、逐年明细表（可在乐观 / 普通 / 悲观间切换）。右轴只画合计，不逐项拆分收支——项数一多会糊成一片、各项的周期差异也读不出来，要看单项请用逐年明细表与参数面板；某类收支全为 0 时对应曲线不出现，也不占图例。
- 参数自动保存到 localStorage 并写入地址栏，「复制方案链接」即可分享整套参数与压力测试设置。
- **方案快照**：把当前参数（收益率 + 全部收支项 + 压力测试设置）命名存进浏览器本地，右上角「快照」抽屉里列表总览，一键载入 / 删除，载入后可在 toast 里撤销。**快照创建后即为只读记录**——参数在创建时深拷贝，名字也不可改，只能载入或删除。**只存参数、不存计算结果**：主图、指标卡、逐年明细都是纯函数，载入后实时重算且与保存时逐位一致；蒙特卡洛是随机模拟、重跑不复现，所以快照刻意不记那个存活率（载入后需重新运行），否则会让人误以为它是可复现的。

# 计算口径

每年只推演一次（按年龄），顺序严格如下：

1. 年初本金产生投资收益：`年初本金 × 该情景年化收益率`
2. 累加当年所有「触发」的收入项
3. 累减当年所有「触发」的支出项

```
年末本金 = 年初本金 + 投资收益 + 收入合计 − 支出合计
```

## 收支项（CashFlowItem）

收入与支出共用同一结构，方向由所在的列表决定：

| 字段 | 含义 |
|---|---|
| `amount` | **单次**发生金额（元/次） |
| `period` | 发生方式：`once` 仅一次；`month` 每 `interval` 个月；`year` 每 `interval` 年 |
| `interval` | 周期间隔，`>= 1`；`period = 'once'` 时无意义（固定 1） |
| `growth` | 单次金额的年涨幅（小数，如 3% 填 0.03） |
| `startAge` / `endAge` | 起止年龄，**两端都含** |
| `enabled` | 关闭后该项当期计为 0（用于找「躺平不破产」的边界） |

周期就是「多久发生一次」，金额是「每次多少」：

| 周期设置 | 含义 | 每年发生次数 |
|---|---|---|
| `once` | 仅在 `startAge` 那年一次 | — |
| `month` + `interval = 1` | 每月 | 12 |
| `month` + `interval = 2` | 每两个月 | 6 |
| `month` + `interval = 12` | 每 12 个月（等价于每年一次） | 1 |
| `year` + `interval = 1` | 每年 | 1 |
| `year` + `interval = 10` | 每 10 年一次 | 触发年 1，其余年 0 |

**金额复利**：`单次金额(年龄) = amount × (1 + growth) ^ (年龄 − startAge)`

`年龄` 的金额 = `单次金额 × 当年发生次数`。涨幅按**年**复利、作用于单次金额，起始年系数为 1。
例：每月 3000 元、年涨 3% → 第 n 年每次 `3000 × 1.03^n`，当年合计 `36000 × 1.03^n`。
因此「换车」这类每 10 年一次的项，第 n 次发生时单次金额已复利了 `10n` 年。

几个容易误读的口径：

- **破产判据**：`survives` 要求「全程任何一年年末本金都未为负」，而不是只看结束年龄的终值。主曲线、三情景与压力测试共用同一判据。
- **破产即截断**：某年年末本金首次为负就终止该情景的模拟，当年缺口保留在结果里。后续年份不再推演——现实中无法以自己组合的收益率无限透支，否则负本金会跟着「复利」滚成雪球，把破产金额严重夸大。因此 `Analysis.simulatedThroughAge` 可能小于 `endAge`，累计收支也只统计到耗尽那年。
- **月周期的不均匀性**：`interval` 不整除 12 时（如每 5 个月），各年发生次数本来就不均（3/2/3/2/2/3…），长期均值才等于 `12 / interval`。卡片上的「年额约」是均值，逐看真实值请查逐年明细表。
- **明细表必须认准当前情景**：三个情景的收支项完全相同，只有年化收益率不同。本金曲线在「悬崖」附近会拉开几十倍差距（悲观情景耗尽那年，普通情景往往还有几百万），所以「悲观 78 岁耗尽」与「普通 77 岁还有 450 万」可以同时为真——那不是「一年花掉 450 万」。表头的情景切换器会明确标注当前显示的是哪个收益率，并且**耗尽那一年必定出现在表里**（它通常不在「每 5 年」的抽样网格上）。
- **递增的基准年**：每项涨幅都从自身 `startAge` 起算，起始年系数为 1（不预先涨一年）。压力测试只对**支出项**做随机游走、收入项涨幅固定，因此波动率为 0 时结果收敛到确定性模型。
- **三档结论**：`verdict()` 把「普通 / 悲观」两组分析归纳为 `safe`（两者都不破产）/ `risky`（普通可以、悲观破产）/ `bankrupt`（普通就破产）。
- **换车模板的等价折算**：模板把「车价从开始年龄复利到首次换车年」预先折算进 `amount`，因此发生年的净支出仍等于
  `车价 × (1 + 车价涨幅)^(年龄 − 开始年龄) × 75%`，与旧版逐字一致（见 `src/lib.test.ts` 的等价性回归）。
- **配置版本**：`STATE_VERSION = 3`。周期语义经历两次不兼容变更（v1 专用分类 → v2 `frequency + cycle` → v3 `period + interval`），旧分享链接与旧本地缓存会**直接失效并回退默认参数**（`STORAGE_KEY` 同步升为 `interestlife.state.v3`，不提供跨版本迁移）。

# 模型假设与局限

这是一个**教学与直觉工具**，不是理财建议。下列简化会系统性影响结论方向，请按需自行加安全边际：

**口径**

1. **名义口径**：收益率与各项涨幅都是名义值，两者相抵才是实际购买力。注意不要一边填「实际收益率 5%」一边又填「生活费涨 3%」，那等于把通胀算了两遍。
2. **无税费、无费率**：投资收益、股息、卖出都不扣税，也没有基金/ETF 管理费。A 股个人资本利得免税只是特例，美股股息预扣 30% 且有利得税。
3. **「生活费」项必须是全口径**：模型不自动包含房租/房贷、子女教育支出，所以「生活费」项要把房租、水电物业、通讯、保险等全部算进去（或另建一个「房租」项）。

**风险建模**

4. **无社保、也无医保**：医疗支出与一次性大额支出默认全额自费，既没有城乡居民医保的报销，也没有商业医疗/重疾险的保费与赔付。这是本模型最大的简化——会让「不交社保」的替代成本被低估，也会让尾部风险被低估。
5. **一次性支出是确定金额，不是概率事件**：压力测试只随机化收益率与各支出项的涨幅，**不含**大病、意外、失能等尾部事件。真实世界里这类事件往往正是压垮躺平的原因。
6. **医疗支出是平滑增长的单一曲线**：未体现「生命末期医疗支出骤升」（现实中临终前数年的医疗费用占一生相当大的比例）。
7. **只有换车、没有养车**：油/电费、保险、保养、停车、违章、年检全部未计入。这部分每年通常上千到数万元，长期影响可能大于换车本身。
8. **长寿风险**：模拟在结束年龄截止，活过结束年龄的部分（以及活过结束年龄后的医疗支出）不计入。

**收益与波动**

9. **确定性情景的收益率是常数**：主曲线与三情景每年都用同一个收益率，不存在「头几年大跌」的序列风险。
10. **压力测试的漂移是「普通收益率」，不是「悲观收益率」**：`monteCarlo()` 抽的是 `N(普通收益率, 收益波动率)`，所以它**不会**重演悲观情景。默认 σ=0.02 时，61 年长期均值的标准差只有 0.26%，成功率几乎等于「普通情景是否破产」的阶跃函数，改「悲观收益率」对结果毫无影响——请不要把 `成功率 100%` 与「悲观情景会破产」当成矛盾，它们是两套假设；要看悲观情景下的生存概率，得把普通收益率调到悲观值（或把 σ 提到 10%~18%）再跑。
11. **压力测试是逐年独立同分布的正态抽样**：这低估了固定支出下的序列风险，且用算术均值做复利会高估长期结果（波动率拖累）。另需注意默认波动率较小，`成功率` 会偏乐观，建议把它调到接近真实组合的水平（股票为主的组合年化 σ 常在 10%~18%）。
12. **硬截断**：收益率被夹在 `[−30%, 60%]`、各支出项涨幅被夹在 `[−5%, 20%]`，两端会有概率堆积，极端情形被削平。

**结构**

13. **车辆假设**：「换车」模板假设起始年龄已持有一辆车、每 10 年换一次，残值固定按「当年车价 × 25%」抵扣，不区分具体车龄的折旧曲线；首次换车在「开始年龄 + 10」。模板把这段复利预先折算进了金额，所以看到的金额不是第一年的车价而是首次换车那次的发生金额。
14. **项数与会话参数有硬上限**：每个列表最多 50 项，周期间隔上限 1200（个月或年）。周期项总是从 `startAge` 开始按固定间隔重复，无法表达「第一次提前/推迟」、不等间隔排期或一年内多次的不同金额。
15. **各项涨幅互相独立**：生活费、医疗、车价等涨幅都是外生给定，不联动，也不与收益率相关。
16. **快照只存在于本机浏览器**：`localStorage` 的 `interestlife.snapshots.v<STATE_VERSION>`，上限 50 条（单条约 1 KB），不随分享链接走；`STATE_VERSION` 变更（参数结构不兼容）时整批作废、不迁移。**快照创建后不可修改**（参数在创建时深拷贝、名称也不可改），只能载入或删除；载入快照只替换参数并清空蒙特卡洛结果——它本来就不可复现，留着上一套参数跑出来的存活率比清空更容易误导。

## 四、在其他项目复用

1. 引入 element-plus 深色基础样式：
   ```ts
   import 'element-plus/theme-chalk/dark/css-vars.css'
   ```
2. 根元素开启深色：`<html class="dark">`（本项目固定深色）。
3. 复制 `src/style.css` 中 `html.dark` 内的语义变量 + element-plus 令牌覆盖到目标项目（注意加载顺序需在 element-plus 样式之后）。
4. 图表如需同款色板，采用第三节的颜色。
